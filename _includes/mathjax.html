{%- comment -%} Math rendering (MathJax 3). Kramdown turns `$$...$$` in the Markdown sources into LaTeX-style delimiters -- `\(...\)` for inline math and `\[...\]` for display math -- which is what MathJax 3 scans for by default, so the `tex` block below just states those delimiters explicitly rather than relying on defaults.
